# Приватність і повідомлення про вразливості

[English](SECURITY.md) · [Українська](SECURITY_UK.md)

Публічний код не містить готових акаунтів, приватних ключів, реальних профілів
або журналів автора. Власні дані після налаштування зберігаються у приватному
сховищі програми/окремому runtime, а не в репозиторії.

Не надсилайте пароль, токен, pairingкод, keystore, повний config.json чи
неочищений архів журналів у публічний issue. Видаліть власні PN/серійні номери,
MAC/IP/домен, точні координати, назву ПК, системні шляхи й імена користувачів.
Діагностика може містити ці дані навіть без явного поля «password».

Для повідомлення достатньо версії, ОС, кроків відтворення й очищеного фрагмента.
Якщо в GitHubрепозиторії налаштовано приватне повідомлення про вразливості,
використайте його; інакше почніть без секретів і погодьте приватний канал
із власником. Не вигадуйте адресу підтримки/пошту автора.

HTTPS API використовує TLS1.3 та перевірку ідентичності. Helper — окремий
HTTPінструмент довіреної LAN: його не можна виставляти в інтернет. Віддалений
доступ до установки та налаштування мережі — відповідальність її власника.

У разі випадкової публікації секрету змініть/відкличте його. Самого видалення
файла недостатньо: значення могло залишитися в історії Git або чужих копіях.
Публічні значення сертифіката/контрольні суми не є приватними ключами.


Вибір мови зберігається локально. Переклад інтерфейсу не надсилає тексти
або дані користувача сторонньому перекладачу. Сирі журнали не змінюються.
