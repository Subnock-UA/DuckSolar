# Інструкції для ШІ

[English](AGENTS.md) · [Українська](AGENTS_UK.md)

Перед змінами прочитайте docs/AI_MAINTENANCE_UK.md, ARCHITECTURE_UK.md і
BUILD_UK.md. Працюйте тільки в публічному checkout та явно визначеній тимчасовій
папці збірки. Не шукайте приклади/ключі/профілі в сусідніх приватних установках.

- Аналіз чи документація не дозволяють реалізацію. Дотримуйтеся команди; стоп/пауза зупиняє роботу.
- Не запускайте реальні збір, перенаправлення логера, записи, sync/міграцію чи робочі служби для тесту. Використовуйте синтетичні дані, тимчасові root і loopbackпорти.
- Зберігайте API3, TLS1.3/pin/SPAKE2, перевірки профілю/ревізій, підтвердження/readback, атомарність, CAS та схеми.
- Не змішуйте b2 з b1. Порожні персональні defaults залишаються порожніми; autoimport b1 заборонений.
- Приватні дані не повинні потрапляти в код, імена, коментарі, fixtures, метадані та байткод. Шляхи й підпис налаштовуються локально.
- Оновлюйте документацію обома мовами й синхронізуйте каталог. Типово англійська. Не змінюйте канонічні значення API/списків та введені поля.
- Для цієї заміни за прямою командою зберігайте b2.0.0/code20000. Не послаблюйте перевірку версій автооновлення.
- Виконайте цільові регресії, tools/audit_public.py і hostтести. Не називайте збірку фізичним прийманням; зафіксуйте межі у VALIDATION_UK.md.
- Не публікуйте, не встановлюйте на фізичні пристрої й не вибирайте персональну Gitідентичність без прямого доручення.
- Не запускайте інших агентів без прямого запиту користувача.
