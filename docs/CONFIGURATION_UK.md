# Налаштування

[English](CONFIGURATION_EN.md) · [Українська](CONFIGURATION_UK.md)

## Обладнання та сервер

| Поле/режим | Що ввести/що означає |
|---|---|
| IP-адреса EyBond | Власна локальна IPv4 логера з переліку пристроїв маршрутизатора |
| PN реєстратора | Серійний номер/PN саме вашого EyBond, без пробілів |
| Без підключення до обладнання | Працює HTTPS API, але не опитує й не переналаштовує логер |
| Звичайний | Локальне опитування та хмарний обмін через сервер |
| Локальне опитування без хмари | Читання логера без ретрансляції до SmartESS |
| Хмарна ретрансляція без локального опитування | Передавання хмарного обміну без власних локальних запитів |
| Запустити/зупинити | Керує збором; зупинка намагається повернути логеру прямий ESSмаршрут |

IP і PN порожні на новій установці; офлайнрежим типовий. Спочатку дізнайтеся
адресу свого логера, за потреби закріпіть її DHCPрезервацією. Телефонсервера
та логер мають бути доступні один одному, без гостьової ізоляції Wi-Fi.
Перемикання режиму застосовується після зупинки й нового запуску.

Програма використовує профіль Daxtromn/EyBond; її читання та дозволені записи
залежать від визначених моделі/прошивки. Не підставляйте профіль чужої моделі.
Параметри та діапазони команди мають пройти перевірку, а зміна — контрольне читання.

## Клієнт: адреси, парування й обліковий запис

1. LAN HTTPS: `https://<адреса серверного телефона>:28766`.
2. Віддалена HTTPSадреса необов’язкова. Для роботи лише вдома залиште її порожньою.
   Доступ ззовні налаштовує власник мережі; перевіряйте TLSідентичність і не
   замінюйте HTTPS на HTTP. Helper для віддаленого API не використовується.
3. Логін і пароль створюєте ви на своєму сервері. Готового облікового запису немає.
4. Код парування отримайте на екрані сервера через його керування паруванням.
   Перевірте відбиток і введіть PN логера. Це різні значення: PN не є паролем.
5. Для першого входу виберіть створення акаунта; надалі використовуйте вхід.
6. Зміна відбитка після перевстановлення сервера потребує свідомого повторного
   підтвердження. Не погоджуйте незрозумілу зміну автоматично.

Клієнт обирає доступний маршрут і відновлює зв’язок. Ручні LAN/remote кнопки
задають тимчасовий пріоритет; недоступний маршрут має резервний перехід.
Пароль не зберігається у профілі; довготривалий токен є приватними даними.
У Windows він захищений DPAPI поточного користувача; копія профілю на інший ПК
може вимагати нового входу.

## Панелі, погода й прогноз

Задайте власний населений пункт або координати, потужність панелей, нахил
(0–90°) та азимут (0–360°, південь180°). Типова потужність1кВт — умовне стартове
значення, а не характеристика вашої установки. До налаштування локації прогноз
не повинен вважатися готовим. Геокодування інтерфейсу орієнтоване на Україну;
для іншої країни задайте координати й перевірте відповідність місця.

Корекція PV типово1.0 (без корекції), нічний поріг0Вт, власне споживання
інвертора0Вт. Внесіть значення, обґрунтовані вашими вимірюваннями. Зміна
моделі розрахунку може зробити похідний кеш несумісним; сирі виміри зберігаються.
Навчання потребує достатнього покриття історії та не створює відсутні виміри.

## АКБ та нічний заряд

Корисна ємність АКБ спочатку не задана. Уведіть її у кВт·год, резерв у відсотках
та ККД. Розрахункова автономність/енергія відрізняється від SOC, отриманого
від інвертора/BMS. Позначайте100% лише після фактичного повного заряду;
не використовуйте цю дію для косметичного виправлення показника.

Нічний заряд вмикайте лише після перевірки допустимих струмів інвертора й АКБ.
Задайте період, струми та джерело заряду. Увімкнений режим керує відповідними
параметрами й блокує конфліктні ручні записи. Вимкнення відновлює збережені
керовані значення до ввімкнення. Адаптивне застосування типово вимкнене;
за недостатніх даних використовується фіксований розклад.

## Лічильник і тарифи

Введіть власні початкові накопичувальні покази: імпорт день/ніч, експорт день/ніч,
дату й час. Не вводьте місячний приріст замість накопичувального регістру.
Для заміни лічильника використовуйте відповідний сценарій, щоб зберегти історію.

Тарифні суми/податки типово0, нічний множник1, рік введення0 (не задано).
Налаштуйте свої ставки й дату введення установки перед фінансовими висновками.
Зелений тариф перевіряється за офіційним джерелом, але потребує правильної
категорії/дати установки; помилка завантаження не повинна стирати ручну ставку.
Гроші за лічильником та розрахункова енергія інвертора мають різне походження.

## Helper і локальні файли

Адреса Helper на обох телефонах порожня. Введіть адресу свого ПК з портом28765,
перевірте його ідентичність, потім передавайте журнали/історію за потреби.
Журнали можуть містити власні адреси, PN, часові дані — не прикріплюйте їх
публічно без очищення.

Низькорівневий серверний config.json належить приватному сховищу застосунку
(`Server/DS_Server_Beta_2/config.json` під його filesDir), а не репозиторію.
Не редагуйте його під час роботи. Основні користувацькі параметри змінюються
через UI/API з перевіркою. Налаштування збірки та Pythonworker описані окремо
в [BUILD_UK.md](BUILD_UK.md).


Публічна установка не підтягує дані попереднього інвертора. Старі CSV, покази
лічильника, стан прогнозу, профілі й акаунти до дистрибутива не включені.
Технічні таблиці підтримуваних моделей/протоколу залишаються довідниками:
поточну модель і значення програма отримує від підключеного обладнання.

## Мова інтерфейсу

Типово використовується англійська. Сервер Android: кнопка «Мова» на головній;
клієнт Android: «Додатково → Мова»; Windowsклієнт та Helper: вибір угорі вікна.
Доступні English та Українська. Вибір зберігається окремо для кожної програми.
На Android екран перебудовується без перезапуску серверної служби; завершіть
незбережене редагування перед зміною мови. Дані, ключі API й значення списків
не переписуються. Системні діалоги можуть використовувати мову ОС; сирі журнали
залишаються мовою оригіналу.
