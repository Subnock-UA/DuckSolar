# Підготовка публікації GitHub

[English](PUBLICATION_EN.md) · [Українська](PUBLICATION_UK.md)

Публікуйте тільки цей очищений корінь. Не створюйте репозиторій у каталозі
своєї робочої установки й не завантажуйте сусідні приватні матеріали.
Для першого випуску створіть нову історію Git із цього дерева.

1. Прочитайте `docs/VALIDATION_UK.md`, запустіть аудит і hostтести.
2. Перегляньте список файлів, також прихованих. `.gitignore` — додатковий
   захист, а не заміна перевірки того, що вже додано до Git.
3. Налаштуйте публічне ім’я та GitHubnoreplyemail у локальному Gitconfig.
   Репозиторій не встановлює ці значення автоматично. Перевірте автора перед commit.
4. Ініціалізуйте Git у цьому каталозі, додайте перевірені файли, перегляньте
   `git diff --cached --stat` і `git diff --cached`, лише потім створіть commit.
5. Створіть власний GitHubрепозиторій і під’єднайте його URL. Код не містить
   чужого username/repository remote. Push — окрема явна дія власника.
6. Додайте готові APK/ZIP як assetsвипуску, а не всередину історії джерел.
   Вкажіть betaстатус, платформу, підпис/його відсутність, SHA256 і обмеження
   приймання. Не додавайте keystore чи паролі.
7. Увімкніть доступний захист від секретів і перевіряйте alerts. Він доповнює
   локальний аудит, але не знає всіх домашніх IP/довільних персональних значень.

Вихідний архів та пакети мають окремі контрольні суми. Для перевірки файла:

```powershell
Get-FileHash .\DS_Server_ver.b2.0.0.apk -Algorithm SHA256
```

Власник може додатково створити приватний JSONсписок небажаних значень **поза
репозиторієм** й виконати `python tools/audit_public.py --denylist-file <файл>`.
Аудит повертає тільки шляхи/типи/рядки, не самі знайдені значення. Він перевіряє
також імена/коментарі як звичайний текст; це не абсолютна гарантія для будь-якого
невідомого секрету. Фінальний пакувальний контроль має включати вкладені
архіви/bytecode, а не лише текстові вихідні файли.

Джерела правил: [GitHub secret scanning](https://docs.github.com/en/code-security/concepts/secret-security/secret-scanning),
[Android application ID та підпис](https://developer.android.com/build/configure-app-module),
[MIT](https://opensource.org/license/mit).
