# Щоденна робота

[English](USER_GUIDE_EN.md) · [Українська](USER_GUIDE_UK.md)

## Головна і стан зв’язку

Головна показує PV, мережу, навантаження та АКБ. Напрями потоків залежать від
свіжих доступних вимірів. Тире означає відсутні/застарілі дані, а не нуль.
Нуль — дійсне числове значення. У «Моніторинг» відкривайте деталі показника:
одиниці, джерело, якість та свіжість. Розрахунковий показник не є прямим виміром.
Непідтверджені трактування не використовуйте як підставу для запису налаштувань.

Якщо показники зникли, відкрийте стан підключення, перевірте сервер,
LAN/віддалений маршрут і статус обладнання. Наявність зв’язку клієнта із сервером
не означає, що сервер зараз отримує свіжу телеметрію від інвертора.

## Графіки та історія

Виберіть день/місяць/рік, джерело Local/SmartESS/Auto, поля та режим.
Потужність вимірюється у Вт/кВт, енергія — у кВт·год; їх не можна порівнювати
як одну величину. Auto обирає дані за правилами походження, а не складає
повторні записи двох джерел. Неповне покриття відображається окремо.

Масштабування й повноекранний режим допомагають дослідити короткий інтервал.
На ПК доступний експорт PNG/PDF/CSV. Великий запит виконується фоновим
завданням із прогресом і можливістю скасування; не очищайте історію заради
повторного відкриття графіка. Повторні запити використовують сумісний кеш.

## Баланс, фінанси, календар і звіти

Баланс підсумовує енергію за період; фінансові результати використовують
покази будинкового лічильника та налаштовані ставки. Перед порівнянням
перевірте однакові періоди й покриття. Календар веде до добового графіка.
Звіти про відключення містять відомі та невизначені інтервали: прогалина
зв’язку сама по собі не доводить відключення зовнішньої мережі.

## Прогноз і факт

Налаштуйте панелі та місце, завантажте погоду; за наявності історії запустіть
навчання. Порівняння прогнозу й факту показує отримані фактичні години без
штучного заповнення відсутніх даних. Виданий прогноз зберігає свій час видачі;
свіжий прогноз залишку дня не повинен замінювати його для оцінки точності.
На новій установці статистика точності порожня до накопичення достатніх даних.

## Параметри й профілі

Відкрийте каталог параметрів, прочитайте опис/поточне значення/межі.
Перевірте, що параметр доступний для запису саме для визначеного профілю.
Підтвердіть зміну; перевірте результат контрольного читання в журналі команд.
Повторювати команду після невизначеної відповіді без перевірки поточного стану
не слід. Профіль налаштувань спочатку показує перелік змін, потім застосовується
після підтвердження; чужий профіль моделі/прошивки має відхилятися.

## Фон, сповіщення і віджет

На Android налаштуйте потрібні типи та пороги сповіщень, дозвіл ОС і фонову
роботу. Надійний фон може витрачати більше батареї. На Windows клієнт має
працювати у треї; вимкнений/сплячий ПК не доставляє нові повідомлення.
Віджет показує останній доступний стан; його відкриття не повинно додатково
опитувати інвертор напряму. Не плутайте свіжість віджета зі станом збору сервера.

## Типові проблеми

| Симптом | Що перевірити |
|---|---|
| Клієнт не підключається | Власна адреса, порт28766, сервер запущений, спільна мережа/маршрут |
| Відбиток змінився | Чи перевстановлено сервер; звірити відбиток на самому телефоні |
| Сервер працює, вимірів немає | Офлайнперемикач, IP/PN логера, Wi-Fi, сумісність профілю |
| Helper недоступний з телефона | `--host 0.0.0.0`, порт28765, приватне правило Firewall, правильна LANадреса |
| Прогноз порожній | Місце, координати, панелі, доступ до погоди, покриття історії |
| Баланс/навчання довго рахується | Прогрес, розмір історії, заряд/пам’ять сервера; не запускати дублікати |
| Оновлення не встановлюється | Новіший code, той самий package/ключ, вільне місце, дозвіл інсталятора |
| Розрахункова АКБ невідома | Власна ємність та обґрунтована опора повного заряду |

Для повідомлення про помилку вкажіть версії, ОС, послідовність дій і очікуваний
результат. Не публікуйте необроблені журнали, QR/коди парування, токени чи
знімки з власними ідентифікаторами; див. [SECURITY.md](../SECURITY_UK.md).


## Мова інтерфейсу

Типово використовується англійська. Сервер Android: кнопка «Мова» на головній;
клієнт Android: «Додатково → Мова»; Windowsклієнт та Helper: вибір угорі вікна.
Доступні English та Українська. Вибір зберігається окремо для кожної програми.
На Android екран перебудовується без перезапуску серверної служби; завершіть
незбережене редагування перед зміною мови. Дані, ключі API й значення списків
не переписуються. Системні діалоги можуть використовувати мову ОС; сирі журнали
залишаються мовою оригіналу.
