# Встановлення

[English](INSTALLATION_EN.md) · [Українська](INSTALLATION_UK.md)

## Вимоги

Android Server: Android 8.0/API26 або новіший, Wi-Fi доступ до EyBond,
вільне сховище для історії та стабільне живлення. Android Client: Android8+
на ARM64 або x86_64; 32-бітний клієнт поточна збірка не містить.
Сервер має ARMv7, ARM64, x86, x86_64. Типові фізичні перевірки попередньої
гілки виконувалися на Android11/13; це не гарантія перевірки b2 на всіх ОС.
Windows-клієнт: Windows10/11 x64. Для запуску з коду потрібен Python з Tk.

## Android Server

1. Завантажте APK сервера з довіреного випуску або зберіть його самостійно.
   Зіставте SHA256 з файлом контрольних сум того самого випуску.
2. Відкрийте APK на телефоні, дозвольте встановлення цьому джерелу й підтвердьте
   системне встановлення. Значок має назву **Duck Solar Server b2**.
3. Відкрийте сервер, надайте дозвіл на сповіщення, якщо ОС його запитає.
4. Для тривалої роботи увімкніть «Робота сервера без обмеження батареї».
   У налаштуваннях виробника телефона також дозвольте фонову роботу.
5. Залиште «Без підключення до обладнання» увімкненим для першої перевірки.
   Натисніть «Запустити сервер». Історія буде порожньою — це нормальний стан.
6. Запишіть показану LAN-адресу та відбиток сервера. Подальші дії —
   [налаштування](CONFIGURATION_UK.md).

Установка b2 не замінює b1: це інший application ID, окреме сховище й порт.
Не видаляйте b1 для встановлення b2. Не вмикайте b2 для того самого реального
логера, поки ним керує b1. Режим без обладнання дозволяє ознайомитися з b2.

## Android Client

1. Встановіть клієнтський APK аналогічно серверному. Значок — **Duck Solar b2**.
2. Відкрийте підключення, введіть HTTPS-адресу сервера з портом28766.
3. Створіть власний обліковий запис або ввійдіть у вже створений на цьому
   сервері; використайте його PN і одноразовий код парування.
4. Зіставте показаний відбиток із сервером. Деталі — у посібнику налаштувань.
5. Дозвольте сповіщення й налаштуйте фон лише за потреби. Примусове зупинення
   застосунку системою вимикає фонові сповіщення до наступного запуску.

## Windows Client

Portable-пакет: розпакуйте весь ZIP, залишивши `_internal` біля EXE. Запустіть
`DuckSolar_PC_Client.exe` або `Start.cmd`. Не переносіть один EXE без залежностей.
Введіть власний профіль підключення через інтерфейс.

За бажанням `Install.cmd` встановлює підписаний пакет у
`%LOCALAPPDATA%\Programs\DuckSolarB2PC\b2.0.0` і створює окремі ярлики b2.
Для непідписаного пакета установник навмисно завершується з поясненням.
Після перевірки походження та SHA256 можна запустити PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -AllowUnsigned
```

Альтернатива — portable-запуск без установника. Windows може попереджати про
непідписаний/новий EXE. SHA256 підтверджує збіг файлів, але не особу видавця.
Для джерельного запуску та підпису власної збірки див. [BUILD_UK.md](BUILD_UK.md).

## PC Helper (необов’язковий)

Варіант із коду: встановіть Python3.11, створіть окреме віртуальне середовище,
встановіть `pc-helper/requirements.txt`, запустіть:

```powershell
python pc-helper/update_server.py --headless
```

Це слухає лише цей ПК. Для Android у довіреній домашній мережі явно задайте LAN:

```powershell
python pc-helper/update_server.py --headless --host 0.0.0.0 --port 28765 --root .\runtime\helper
```

У брандмауері дозвольте TCP28765 тільки для приватної мережі. На Android введіть
`http://<LAN-адреса вашого ПК>:28765`. Перед передаванням звірте ідентичність
Helper. Не відкривайте цей HTTP-порт в інтернет: він призначений для довіреної LAN.
Підготовка історії працює через окремий Pythonworker. У portable EXE Helper
задайте `DS_WORKER_PYTHON` на свій Python з установленими залежностями;
запуск із коду типово використовує поточний Python.

## Оновлення і видалення

Оновлення b2 повинно мати ті самі application ID та ключ видавця, новіший code.
«Перевірити оновлення» читає каталог, «Встановити оновлення» завантажує й
перевіряє пакет та відкриває Androidінсталятор. Сервер створює checkpoint перед
встановленням. Ключ debugзбірки призначений для перевірок; не змінюйте ключ
між випусками, які мають оновлюватися поверх.

Перед видаленням збережіть потрібні дані власним резервним копіюванням.
Видалення Androidпрограми видаляє її приватне сховище. На ПК видалення папки
програми не очищає профіль у DuckSolarB2. Щоб прибрати фон, спочатку вимкніть
автозапуск у клієнті й закрийте його через трей.


## Мова інтерфейсу

Типово використовується англійська. Сервер Android: кнопка «Мова» на головній;
клієнт Android: «Додатково → Мова»; Windowsклієнт та Helper: вибір угорі вікна.
Доступні English та Українська. Вибір зберігається окремо для кожної програми.
На Android екран перебудовується без перезапуску серверної служби; завершіть
незбережене редагування перед зміною мови. Дані, ключі API й значення списків
не переписуються. Системні діалоги можуть використовувати мову ОС; сирі журнали
залишаються мовою оригіналу.

Двомовна заміна має той самий номер b2.0.0/code20000. Для заміни вже встановленої
b2.0.0 відкрийте новий APK вручну (той самий ключ підпису); автооновлювач
не пропонує однаковий code. На Windows закрийте b2 й замініть повний пакет.
