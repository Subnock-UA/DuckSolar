# Duck Solar b2.0.0

[English](README.md) · [Українська](README_UK.md)

Моніторинг сонячного інвертора Daxtromn через реєстратор EyBond: поточні показники,
графіки й історія, баланс електроенергії, лічильники, прогноз генерації,
сповіщення та контрольоване керування підтримуваними параметрами.

Публічна бета для самостійного встановлення. Підтримка залежить від моделі та
прошивки; наявність EyBond сама по собі не гарантує сумісність усіх команд.
Мови інтерфейсу — англійська та українська; типово англійська. Код і документація — MIT; сторонні компоненти
мають власні ліцензії (див. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES_UK.md)).

## Які програми потрібні

| Програма | Для чого | Обов’язковість |
|---|---|---|
| Android Server | Зв’язок із логером, збір історії, розрахунки, HTTPS API | Основний сервер |
| Android Client | Перегляд і керування з телефона | Один із клієнтів |
| Windows Client | Перегляд і керування з ПК | Альтернатива/доповнення Android-клієнта |
| PC Helper | Локальна передача оновлень, журналів та підготовка історії | Необов’язковий |

Схема: **EyBond ↔ Android Server ↔ Android/Windows Client**.
Helper не опитує інвертор і не замінює Android Server. Дані збираються на
серверному телефоні; закриття клієнта не зупиняє сервер.

## Початок роботи

1. Прочитайте [інсталяцію](docs/INSTALLATION_UK.md) та встановіть потрібні програми.
2. На сервері спочатку запустіть режим «Без підключення до обладнання».
3. Налаштуйте власні адреси, PN логера та обліковий запис за
   [інструкцією налаштувань](docs/CONFIGURATION_UK.md).
4. Під’єднайте клієнт через парування, перевіривши відбиток сервера.
5. Перед роботою з реальним логером переконайтеся, що інший сервер ним не керує.
6. Повсякденна робота описана в [посібнику користувача](docs/USER_GUIDE_UK.md).

У b2 немає готових логінів, паролів, PN, MAC, домашніх IP чи координат.
Їх вводить власник установки. Адреси `192.0.2.x` та `198.51.100.x` у тестах —
синтетичні приклади; не використовуйте їх як адресу вашого пристрою.

## Відокремлення b2

Android application ID: `ua.ducksolar.b2.server` та `ua.ducksolar.b2.client`.
HTTPS API сервера: **28766**; типовий порт Helper: **28765**.
Windows-клієнт зберігає дані у `%LOCALAPPDATA%\DuckSolarB2\PCClient`, має
окремі ярлики, автозапуск і блокування другого екземпляра.
Helper типово використовує `%USERPROFILE%\.ducksolar-b2-helper` і слухає
лише `127.0.0.1`; LAN вмикається явно параметром `--host`.

b2 встановлюється поруч з b1, не є оновленням поверх b1. Профілі й архіви
автоматично не копіюються. Одночасне активне підключення двох серверів до
одного фізичного логера не підтримується: у b2 залиште режим без обладнання,
доки інший сервер використовується для цієї установки.

## Вибір мови

На сервері Android натисніть «Мова» на головному екрані; у клієнті Android —
«Додатково → Мова». На Windows вибір є у верхній частині вікна клієнта та Helper.
Мова зберігається окремо для кожної програми, типово англійська навіть за
української мови ОС. На Android екран перебудовується; завершіть незбережені
правки перед зміною. Серверний збір не перезапускається.

Ця замінна двомовна збірка зберігає b2.0.0/code20000. Автооновлення її поверх
такої самої версії не пропонує: відкрийте APK вручну, зберігши той самий ключ
підпису, або замініть повний Windowsпакет після закриття клієнта.
